# Daniyar Guide · Bar & Mix Lab

A free, single-page bar field guide: zero-proof recipe library, flavor pairings, Mix Lab,
house preps, inventory & expiry tracker, hygiene reference (SFDA + Food Safety) and pro tips.

Open `index.html` in any browser, or use the GitHub Pages link on this repo. Works on phone and desktop.

> The hygiene section is a practical overview, not an official translation of SFDA rules —
> consult SFDA / a sanitary inspector before licensing a food-service outlet.
